## 📋 Contenu

- **Projets** : Présentation de 5 projets réalisés (Soldier IA App, Hackintosh, Docker LAN, Nix, Qt Applications)

- **Infrastructure Réseau** : Projets réseau
- **TP et Veille Technologique** : Documentation technique

## 🚀 Fonctionnalités

- Design responsive (mobile, tablette, desktop)
- Navigation fluide et intuitive
- Cartes d'expansion pour les stages
- Images optimisées pour les projets

## 🛠️ Technologies

- HTML5
- CSS3 (variables CSS, flexbox, grid)

- Font Awesome 6.0.0 pour les icônes

## 📱 Responsive Design

- Breakpoints: 600px, 680px, 768px, 1024px+
- Testé sur différents appareils
