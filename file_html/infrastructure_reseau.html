Infrastructure Réseau

Déploiement complet d'une infrastructure réseau

Conception et mise en place d'une infrastructure réseau d'entreprise virtualisée sur Proxmox. Deux situations professionnelles couvrant l'administration système, la supervision proactive, et la gestion complète du parc informatique d'une entreprise fictive.

Candidat Ebelle Makongue N. Jean-Pascal
Établissement Lycée Saint-Rémi, Amiens
Environnement Proxmox VE → VMware
Entreprise fictive TechNova Solutions

Les deux situations

Situation 1 — Administration réseau

Infrastructure réseau interne

pfSense · Active Directory · DNS · DHCP · GPO

Mise en place de l'infrastructure complète de TechNova Solutions : pare-feu pfSense assurant le routage entre la DMZ et le LAN utilisateurs, domaine Active Directory centralisé, services DNS et DHCP, et stratégies de groupe déployées sur les postes.

  • pfSense — 3 interfaces, NAT, routage inter-VLAN, DHCP sur 2 zones
  • Windows Server — Active Directory, domaine technova.local
  • DNS intégré à l'AD, zones directe et inverse
  • Jonction du client Windows au domaine
  • 3 GPO : sécurité, bureau, lecteur réseau partagé
Situation 2 — Supervision réseau

Supervision avec Zabbix

Zabbix Server · Agents · Triggers · Dashboard

Déploiement d'une solution de supervision proactive sur une VM Debian dédiée. Surveillance en temps réel de l'ensemble du parc via l'interface web Zabbix — aucune ligne de commande pour l'administration courante.

  • VM Debian 12 dédiée — Zabbix Server + MariaDB + Apache
  • 4 hôtes supervisés : Windows Server, Debian DNS, Client, pfSense
  • Agents Zabbix sur Windows (MSI) et Debian
  • Triggers : CPU, RAM, disque, disponibilité
  • Dashboard personnalisé — test de panne validé

Stack technique

Pare-feu / Routeur pfSense WAN 192.168.28.33
AD / DNS / DHCP Windows Server 2022 192.168.1.10
DNS secondaire Debian 12 192.168.1.40
Poste utilisateur Client Windows 192.168.2.x (DHCP)
Supervision (Docker) Zabbix 7.x Conteneurs : Server + DB
Hyperviseur Proxmox VE → Migration VMware
